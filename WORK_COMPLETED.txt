TECHNICAL NOTES
─────────────────────────────────────────────────────────────────────────────

Architecture:
  • Next.js 16 (Turbopack) with App Router
  • Supabase for PostgreSQL + Auth + RLS
  • Google Gemini API (free tier) for AI
  • Service Worker for offline support
  • localStorage for local-first experience

Security:
  • All Supabase queries use RLS (Row Level Security)
  • User auth verified on API routes (server-side)
  • User ID stored with all data (user_id foreign key)
  • API route (/api/assistant) checks auth before proxying

Performance:
  • Indexes on all user_id columns for fast queries
  • Service worker caching for faster page loads
  • Static page pre-rendering (22 pages)
  • Background sync doesn't block UI
